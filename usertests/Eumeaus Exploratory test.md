# Eumeaus - Exploratory test

## §1 - Launching screen

### §1.1 Open case
User should able to browse to a case. Not only type the correct path.

### §1.2 New case
Same as §1.1

### §1.3 Browse a directory
Same as §1.1

## §2 - Plugins screen

### 2.1 List plugins
User should be able to browse to the pluginspath. Not only type the correct path.

### §2.2 Install plugins
See §2.1

## §3 Entities

### §3.1 Facts
User should be able to add facts to an entity

### §3.2 Links
User should be able to create links to other entities by selecting them from, for example, a dropdown. Also the type of link should be selectable (currently hardcoded to "AssociatedWith")

## §4 Scans

### §4.1 New scan - overall
User needs to select (or currently type) path to the plugins everytime they wants to do a scan. Path to plugins should be a one time (changeable) setting.

### §4.2 New scan - scan
User needs to type the value of an existing entity in order to perform a scan. This value should be selectable.
